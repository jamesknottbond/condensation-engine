# condensation-engine

Generated WebGL engine bundle for the "Condensation" Framer code component
(fogged-glass wipe-reveal hero effect). Not intended for standalone use —
it is imported by a Framer code file via a SHA-pinned jsDelivr URL.

Bundles [raindrop-fx](https://github.com/SardineFish/raindrop-fx) (c) SardineFish, MIT,
and zogra-renderer (c) SardineFish, MIT. Bundle itself (c) James Knottbond.
